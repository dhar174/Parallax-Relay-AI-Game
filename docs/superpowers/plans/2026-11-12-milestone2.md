# Parallax Relay Milestone 2 Implementation Plan

> Historical archive-build record (November 12, 2026). Delivery constraints and
> instructions below describe that completed milestone, not current repository
> policy. See [AGENTS.md](../../../AGENTS.md) and [ROADMAP.md](../../../ROADMAP.md).

> Execute inline, test-first, in the isolated copy of the supplied archive.

**Goal:** Run independent OpenAI, Claude and Gemini players with sealed turns and public chat.
**Architecture:** Existing pure engine plus immutable observation requests, async provider
adapters, a phase-barrier orchestrator and a local CLI/replay recorder.
**Tech stack:** Python 3.11+, Pillow, Pydantic 2, httpx async REST adapters, unittest.
**Spec:** ../specs/2026-11-12-milestone2-design.md

## Global constraints
- Three active roles only: SPECTRA, PYRA, FLUX; no engine/physics redesign.
- Private data stays role-local; world snapshots are spectator-only.
- Default two chat passes, then sealed actions, all concurrent within each pass.
- No actual API calls or secrets needed for offline tests or mock matches.
- No new account keys created by the build and no publishing or repository pushes.

## Review focus
- Slow/failed requests must not expose partial phase responses or advance physics early.
- Role-private heat, item data, notes and objectives must not leak through history/events.
- Malformed outputs and HTTP faults must not cause unbounded retries/spend.
- Partial logs must survive failure, reject output-directory overwrites, and exclude keys.
- HTTP wire requests must carry the correct images/schema and disable hidden retries.
